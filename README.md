# Animated Visuals Tool

Локальна браузерна утиліта: з власних скриншотів збирає анімований візуал (GIF і MP4) для постів. Без підписок, водяних знаків, акаунтів, сервера й AI.

## Статус
Каркас: модель сцени, `renderScene`, експорт GIF/MP4, тонке прев'ю. Повного інтерфейсу ще немає.

## Як запустити
```bash
npm install
npm run dev
```
Потім відкрити http://localhost:5173. Тест-прототип (spike) лежить на /spike.html.

## Файли
- `CLAUDE.md` — бриф і правила роботи
- `DECISIONS.md` — журнал рішень
- `src/` — код (`model/` модель, `render/` малювання, `export/` експорт)
- `spike/` — тест-прототип
- `docs/` — документація
