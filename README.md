# Animated Visuals Tool

Локальна браузерна утиліта: з власних скриншотів збирає анімований візуал (GIF і MP4) для постів. Без підписок, водяних знаків, акаунтів, сервера й AI.

## Статус
Працює: завантаження картинок, анімація (зум, переходи, криві), прев'ю, експорт GIF/MP4 з підгонкою під розмір, збереження й відкриття проєкту.

## Ліцензія
AGPL-3.0-or-later (див. `LICENSE`). Її вимагає бібліотека кодування GIF gifski-wasm. Це стосується коду інструмента: **готові GIF, MP4 і PNG, які ти створюєш, лишаються твоїми**, їх можна використовувати комерційно. Якщо викладаєш змінену версію інструмента публічно, її код теж має бути відкритим.

## Як запустити
```bash
npm install
npm run dev
```
Потім відкрити http://localhost:5173. Тест-прототип (spike) лежить на /spike.html.

## Файли
- `CLAUDE.md` — бриф і правила роботи
- `DECISIONS.md` — журнал рішень
- `src/` — код (`model/` модель, `render/` малювання, `export/` експорт)
- `spike/` — тест-прототип
- `docs/` — документація
