# Animated Visuals Tool

Локальна браузерна утиліта: з власних скриншотів збирає анімований візуал (GIF і MP4) для постів. Без підписок, водяних знаків, акаунтів, сервера й AI.

## Статус
Підготовка. Коду застосунку ще немає. Зараз іде перевірка технологій (див. розділ 9 у `CLAUDE.md`).

## Як запустити
Поки нічого запускати: застосунок ще не створений. Коли з'явиться, тут буде одна команда для запуску в браузері.

## Файли
- `CLAUDE.md` — бриф і правила роботи
- `DECISIONS.md` — журнал рішень
