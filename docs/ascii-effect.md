# ASCII-вигляд кадру (дизайн, затверджено 2026-11-06)

Ціль: кадр (скриншот, рендер, логотип PNG/SVG) перетворюється на символи (`@#*+-.`), форма впізнається за світлотінню. Референс: Projector.

- **Дані:** `Frame.ascii?: Partial<AsciiSettings>`. Немає блоку — кадр як раніше (старі проєкти не ламаються).
- **Малювання:** `src/render/ascii.ts` (чиста функція). `drawFrame` малює кадр (рух, шари) у тимчасове полотно, потім символи кладуться у вікно вмісту. Тому працює в прев'ю, GIF, MP4, PNG і в переходах.
- **Символ за яскравістю:** «лінійка» від щільного до легкого. Опція Edges підсилює контури (Собель) для чіткішої форми.
- **Джерело форми:** яскравість (скриншоти, рендери) або прозорість (плоскі логотипи).
- **Колір:** один колір або колір із картинки; тло прозоре чи колір.
- **Пресети:** Reference, Mono black, Mono white, Color mosaic (у коді).
- **UI:** розділ «ASCII» у вкладці Image вибраних кадрів; діє на всі вибрані.
- **Ризик:** мерехтіння символів при русі (символ перестрибує біля порогу). Перевірити; якщо є — згладжування між кадрами.
- **Не входить:** анімація розсипання в символи, власні набори в пресетах, 3D (етап Б).
