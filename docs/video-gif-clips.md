# Відео і GIF у кадрах (2026-11-06)

- Кадр може бути статичною картинкою, відео (MP4/MOV H.264, WebM) або анімованим GIF; усе змішується в одному проєкті. Статичний GIF — звичайна картинка.
- `Layer.clip` (`ClipInfo`): kind, duration, start/end (обрізання), speed, loop, poster (мініатюра). `Layer.src` — data URL файлу, як у зображень.
- Тривалість кадру = довжина кліпу `(end-start)/speed`, якщо власної тривалості немає (`frameDuration` у defaults.ts).
- Зміна тривалості кадру: режим `defaults.clipFit` — `speed` (за замовчуванням: міняється швидкість, кліп цілий) або `trim` (обрізати / повторити).
- Декодування: відео — Mediabunny `CanvasSink` (кеш 60 кадрів, сітка 60/с, довга сторона ≤ 1600 px); GIF — `ImageDecoder` браузера (усі кадри в пам'яті). Нових залежностей немає.
- Малювання синхронне (`ClipAsset.peek`), декодування асинхронне: прев'ю перемальовується по `onClipFrame`, експорт перед кожним кадром чекає `prepareClips`.
- Фон і накладка лишаються лише статичними.
- **Звук: поки ігнорується, на виході MP4 без звуку. Місце для нього — `src/media/clipAsset.ts` (поруч із відео-доріжкою) і `exportMp4.ts` (аудіо-доріжка виходу).**

## Шари всередині кадру (2026-11-06)
- Кадр може мати кілька шарів (`Frame.layers`): нижній — основний, поверх можна додати картинку, GIF чи відео («+ Add layer» у розділі «Layers in frame»). Кожен шар має власні Fit/Fill, розмір, зсув, поворот; редагується вибраний шар (у списку й мишею на артборді).
- Тривалість кадру береться з першого шару з кліпом. Фон і накладка проєкту лишаються загальними й статичними.
